## 📌 Projetos em Destaque

### 📊 [olist-analise-vendas](https://github.com/TalisonAzzini/olist-analise-vendas) · *em andamento*
Análise do dataset público de e-commerce da Olist (Kaggle), com foco em **vendas por região**, **relação entre avaliações e prazo de entrega** e **ticket médio**.
- Limpeza e tratamento dos dados no Excel, com dados brutos preservados e decisões documentadas
- Modelagem relacional e medidas em DAX no **Power BI**, com dashboard interativo
- **Stack:** Excel • Power BI • DAX

### ⚙️ [helpdesk-api](https://github.com/TalisonAzzini/helpdesk-api)
API REST para gerenciamento de chamados de suporte técnico.
- Autenticação **JWT**, controle de acesso por cargo e regras de negócio com **Spring Security**
- Paginação e filtros por status, prioridade e cargo, com persistência em **PostgreSQL**
- Script em **Python** (pandas + matplotlib) que consome a API e gera gráficos por status, prioridade e técnico
- **Stack:** Java 21 • Spring Boot • PostgreSQL • Python
